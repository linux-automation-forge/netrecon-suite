# Not a real python requirements file - bash doesn't install stuff from
# these. This is the shopping list. The script checks every one of these
# at runtime and just skips whatever you don't have, so technically you
# only NEED the "required" block. Everything else makes it better.
#
# Debian/Kali names below - on Arch most of these are the same name,
# except: dnsutils=bind-tools, mtr-tiny=mtr, tshark=wireshark-cli

coreutils       (timeout, date, tee, stat, find...)

curl
